## Question 24: Synchronization and Deadlocks [20 marks]

**(a)** A shared integer `counter` initially equals 10. Thread A performs `counter = counter + 1`, and Thread B performs `counter = counter - 1`. The operations are not atomic. The following interleaving occurs:

```text
1. A reads counter into its local register.
2. B reads counter into its local register.
3. A adds 1 to its register.
4. B subtracts 1 from its register.
5. A writes its register to counter.
6. B writes its register to counter.
```

State the final counter value, the result expected if both updates were serialized, and the concurrency problem. Describe how a mutex should protect the updates. **[6 marks]**

**(b)** A connection pool has three identical connections. Explain how a counting semaphore initialized to 3 controls access, including what happens when a fourth thread requests a connection before any of the first three releases one. Distinguish this semaphore from a mutex in terms of ownership. **[4 marks]**

**(c)** A consumer waits until a shared queue is nonempty. Explain how a condition variable and mutex should be used. Your answer must describe mutex release, reacquisition and the need for a predicate loop. **[4 marks]**

**(d)** Thread X holds lock A and requests lock B. Thread Y holds lock B and requests lock A. Name the four necessary conditions for resource deadlock. Explain how a consistent global acquisition order prevents this situation. **[6 marks]**
