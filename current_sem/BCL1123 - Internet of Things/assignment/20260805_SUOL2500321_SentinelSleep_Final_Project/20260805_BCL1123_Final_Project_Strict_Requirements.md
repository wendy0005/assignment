# BCL1123 Internet of Things — Final Project Strict Requirements

Source: `BTL_BCL1123FinalProjectFile.pdf` (five pages). This checklist controls the final-project submission.

## Required implementation

- [ ] Execute the previously submitted SentinelSleep IoT proposal.
- [ ] Use VS Code and Wokwi for implementation and simulation.
- [ ] Connect the ESP32 simulation to Blynk or a comparable cloud dashboard.
- [ ] Demonstrate stable hardware integration and simulation.
- [ ] Demonstrate reliable real-time cloud data transmission and reconnect logic.
- [ ] Provide an intuitive dashboard with readings, trends, controls and alerts.
- [ ] Comment code that reads sensors, processes data, controls actuators and communicates with Blynk.
- [ ] Explain Wi-Fi authentication, encrypted cloud transport, token protection and access control.
- [ ] Explain the implemented system’s unique contribution.

## Required report order

- [ ] Cover page.
- [ ] Logical table of contents.
- [ ] Executive summary.
- [ ] Implementation explanations with screenshots, photographs, diagrams, code snippets and flowcharts.
- [ ] Security components.
- [ ] Reflections covering actual challenges and possible solutions.
- [ ] Summary.
- [ ] APA citations and references; no Wikipedia.
- [ ] Accessible shared-folder URL.

## Formatting

- [ ] Submit the report as DOCX.
- [ ] Times New Roman, 12 point, justified, first-line indentation and 1.5 spacing.
- [ ] Consistent headings/subheadings and appropriate emphasis.
- [ ] Use portrait and landscape sections where required.
- [ ] Use page/section breaks and section-appropriate headers/footers.
- [ ] Format and caption every picture.

## Submission package

- [ ] DOCX report.
- [ ] MP4 demonstration video, maximum 15 minutes.
- [ ] Presenter camera on and face visible throughout the video.
- [ ] Complete VS Code project folder.
- [ ] `readme.txt` containing examiner Blynk login credentials and run instructions.
- [ ] Upload all components to one shared folder.
- [ ] Verify the folder and every file can be opened without requesting access.
- [ ] Submit the share link in the LMS before its deadline.
